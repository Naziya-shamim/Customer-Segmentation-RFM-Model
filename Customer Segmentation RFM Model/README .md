# Customer Segmentation using RFM Model

## 📌 Project Objective
To segment customers based on their purchasing behavior using RFM (Recency, Frequency, Monetary) model, helping businesses target customers effectively for marketing campaigns.

## 📊 Business Problem
E-commerce and retail companies need to identify their most valuable customers, at-risk customers, and lost customers to optimize marketing spend and improve retention.

## 📁 Dataset Description
- **Source:** Generated realistic dataset (100 customers, 1000+ transactions)
- **Customer Master:** 100 rows, 17 columns
- **Transactions:** 1000+ rows

## 🛠️ Tools Used
- Power BI Desktop (DAX, Power Query)
- GitHub

## 📈 Key Metrics (KPIs)
| KPI | Value |
|-----|-------|
| Total Customers | 100 |
| Total Revenue | ₹26M |
| Retention Rate | 99% |
| Average Order Value | ₹5.51K |
| Loyalty Score (Avg RFM) | 8.6 |

## 📊 Dashboard Features
- KPI Cards, Segment Distribution, Revenue by Segment, Loyalty Status, Revenue by Region, RFM Score Distribution
- High-Value Customers Table, At-Risk Customers Table
- Slicers: Region, Age Group, Gender, Loyalty Status
- Insights & Recommendations Page

## 🔍 Key Insights
- 85% customers are "At Risk" – need re-engagement campaigns
- No Champions identified – opportunity to improve loyalty program
- Retention rate: 99%

## ✅ Recommendations
- At-Risk customers: Send 15-20% discount coupons
- Loyal customers: Offer VIP program
- Introduce Platinum tier to create Champions
